The console posts {"query": "..."} to /query. If that call fails it falls back to demo data so the page still shows something.

  • answer — the text from agent 2. This is the only field the answer panel shows.
  • report.sources — one entry per article, each with a title, url, snippet and origin.
  • stats — optional numbers for the telemetry bar.

Extra fields are ignored, and a bare {"answer": "..."} works on its own.
